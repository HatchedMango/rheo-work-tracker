# Rheo

Keep work streams, agent context, and daily progress connected.

Rheo (REE-oh) is a local Mac app for following work across Claude Code and Codex chats. See what can move forward, what it unlocks, and what needs your attention. Keep working in your usual agent chats; Rheo keeps goals, decisions, unfinished changes, and handoffs together.

## What it does

- Organizes active work by prerequisite flow, with completed work in a compact list.
- Puts related agent chats beside the work they belong to.
- Focuses requests for your input on the action, how to do it, and why it matters.
- Tracks completed changes against a daily goal, including progress beyond the target.
- Helps your agent bring existing projects into Rheo using its current context.

Each Mac has its own local work and fresh agent connections. Rheo does not synchronize between devices or import historical chats automatically. Agents execute work through their usual permissions; Rheo records context and progress.
