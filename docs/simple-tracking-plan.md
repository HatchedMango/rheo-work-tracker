# Track work without acceptance chores

Implement the user's November 12 simplification: Work Inbox records work and relationships; the agent follows the user's authorization in chat. Remove accept/decline and coverage management from the current UI and agent workflow. Tracking or a cooperative claim never grants execution authority.

New changes use an explicit tracked assignment state; new streams are active tracking records. Existing proposals and historical decisions remain unchanged in storage. Claims no longer require acceptance/coverage, but still respect closed/delivered/declined work, paused/closed ancestors, revisions, leases and exclusive resources. Retain legacy decision APIs/data for compatibility and history, without surfacing them as required steps. Direct scope/context maintenance is versioned tracking, not a human approval.

Needs you contains only deliberately raised questions and human actions. No automatic proposal, scope, coverage, delivery or review chores. Cards show the short request, stream context and optional Open chat link; collaboration and answer synchronization stay in the agent chat. Preserve full requests, dependencies, answers and provenance in details/history.

Store optional conversationUrl on questions and human actions. Validate HTTP(S) without embedded credentials, or the documented local Codex existing-chat form codex://threads/UUID with no query/fragment. Omit the link when no reliable URL is available; never synthesize it from a cooperative claim UUID or assume a Claude terminal session is a web chat. Native navigation opens only clicked validated destinations, never scripts, new-chat commands, settings or plugin installation URLs. Reference: https://learn.chatgpt.com/docs/reference/commands#deep-links (checked November 12, 2026). Local Codex links depend on the chat and app being available on the same computer; this does not promise remote-host or Claude terminal navigation.

Add an idempotent migration preserving old records, decisions and request text. Update shared MCP/client guidance, then verify new intake/claim behavior, explicit-only attention, response synchronization, unsafe link rejection, browser presentation and packaged native navigation. Back up the installed data before updating the local app. Do not implement immutable plans, automatic execution, a scheduler, new connection permissions or the broader parked redesign.
