# Work Inbox 0.8.1 — private Mac trial

A local Apple Silicon Mac app for seeing goals, agent progress, related work and actual questions/actions. Work stays on the Mac; agents connect locally through MCP. There is no execution worker or cross-device sync.

This trial adds portable onboarding and local-file exclusions, source/desktop CI definitions, versioned installer filenames, SHA-256 checksums, build provenance and release payload checks. MCP reports the package version consistently. It retains the stream map, explicit start/delivery dependency reports and cooperative loop guidance from 0.8.0/workflow 1.6.0.

Download the **macOS arm64 DMG**, matching `.build.json` and `SHA256SUMS`. Check the checksum, drag Work Inbox into Applications, launch it once, and create a new agent connection on that Mac. No Node installation is needed for the packaged app. The ZIP is an alternative packaging of the same app. See the repository's `docs/second-mac-trial.md` for the pilot and backup/update steps.

Requirements: Apple Silicon, macOS 13+. This private trial is **ad-hoc signed and not notarized**. macOS or managed-device policy may block downloaded copies; build from the private source checkout if permitted or wait for a signed/notarized distribution. Do not disable device protections. No public license decision is made by this release.

Local automated checks and packaged helper/SDK checks do not verify automatic hooks in a real Codex/Claude session, work-laptop policy, fresh-machine download behavior, or human acceptance. Those are trial observations still to collect. Keep the existing development Mac's database and credential files off the other Mac and out of GitHub. Each installation owns separate work.
