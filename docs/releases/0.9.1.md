# Rheo 0.9.1 — Mac trial

Download and install Rheo without a GitHub account or access to its private development repository.

- Public DMG/ZIP downloads with build metadata and SHA-256 checksums.
- Active work arranged by dependency flow, with connected branches kept together and actionable work in the first layer. Independent work uses a compact grid; narrower windows flow vertically.
- More usable stream-page width, cleaner spacing, and completed work in a compact list below active work.
- PolyForm Shield 1.0.0 and required project/third-party notices included in the app.

## Install

Requires **Apple Silicon and macOS 13+**. Download the DMG and `SHA256SUMS`, verify the checksum, then drag **Rheo** into Applications. The ZIP contains the same app as an alternative. The runtime is included; no Node installation or source checkout is needed.

See the [installation and agent setup guide](https://github.com/HatchedMango/rheo-downloads/blob/main/INSTALL.md) for checksums, connecting Claude Code or Codex, bringing in existing projects, and updates/backups.

Existing installations retain their local work, connections, and legacy Work Inbox data folder. Quit Rheo and back up the whole data folder before updating. Each Mac uses separate local work and fresh agent connections; there is no cross-device sync.

## Trial limits

This build is **ad-hoc signed and not notarized**. macOS or work-device policy may block it. Keep device protections enabled; wait for an approved Developer ID signed/notarized build if blocked.

Actual installation, client trust/reload, and automatic Claude Code/Codex hooks must still be verified on the receiving Mac. Publishing a downloadable installer does not establish those results.
