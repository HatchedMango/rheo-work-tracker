# Rheo 0.9.0 — private Mac trial

Rheo, formerly Work Inbox, keeps work streams, progress and agent context connected. This private trial includes the current Mac app and everything needed to connect a local Claude Code or Codex client; a separate Node installation is not required.

- A new stream mark shared across the sidebar, favicon, Dock and menu bar, with a clean center join at small sizes.
- **Set up existing work**: choose active project folders and give each project's prompt to its current agent chat. The agent captures a focused handoff, reuses matching streams/unfinished changes and installs project tracking. The app shows received context and current checkpoints; preparing prompts creates no work or completion credit.
- Claude Code connections now work with existing databases. The upgrade preserves existing connections and credential references.
- Active work in a map and finished work in a compact list, with automatic narrow-window stacking and no view switcher.
- Cleaner stream-page spacing and prerequisite arrows that disappear from finished cards, while recorded relationships stay in the details. Integrated chat links, automatic Start/Resume handoffs, focused Needs you guidance and a daily completed-change goal with over-target progress. Human actions such as signing into GitHub do not count as completed changes.

## Install

Requires **Apple Silicon and macOS 13 or newer**. Download the DMG, matching build metadata and `SHA256SUMS`. Verify the DMG checksum, drag **Rheo** into Applications, then launch it once. The ZIP contains the same app as an alternative.

On the work Mac, create a fresh Claude Code or Codex connection in **Connections**, verify a real client tool call, then continue into **Set up existing work**. Use that Mac's project paths and available chat context. Each Mac has its own work and credentials; there is no cross-device synchronization or automatic historical-chat import. See [the second-Mac guide](https://github.com/HatchedMango/rheo-work-tracker/blob/main/docs/second-mac-trial.md).

Existing local installations retain their Work Inbox data folder and stable MCP launchers. Quit and back up the entire data folder before replacing the app. Schema migration 0013 expands Claude Code connection compatibility; keep the matching prior app and stopped-data backup for rollback.

## Trial limits

This build is **ad-hoc signed and not notarized**. macOS or work-device policy may block a downloaded copy. Where permitted, build from the private source; otherwise use a Developer ID signed/notarized build when available. This trial does not change device protections or establish a public license.

Automated source, browser and packaged native checks cover the local implementation. Actual work-Mac installation, client trust/reload and automatic Claude Code/Codex hook behavior must still be observed on that machine. Rheo stores shared context and progress; agents execute work in their usual chats.
